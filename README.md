RetailPro — Proyecto de Data Analytics
Descripción del proyecto
RetailPro es un proyecto de análisis de datos comerciales desarrollado durante el curso de Data Analytics de Coderhouse. Su objetivo es analizar información de ventas, productos y clientes mediante consultas SQL para obtener información útil para la toma de decisiones del negocio.
**Repositorio:** [Coderhouse-Data-Analytics](https://github.com/candeestadella/Coderhouse-Data-Analytics)
Herramientas utilizadas
•	SQL Server: gestión y consulta de la base de datos.
•	SQL Server Management Studio (SSMS): ejecución y administración de consultas SQL.
•	GitHub: almacenamiento y documentación del código del proyecto.
•	Power BI: herramienta utilizada en etapas posteriores para el análisis y la visualización de datos.
Base de datos
El proyecto utiliza la base de datos Ventas_Tech_DB y trabaja con información relacionada con ventas, clientes, productos y categorías.
Consultas SQL desarrolladas
Entre los análisis realizados se encuentran:
•	Resumen mensual: facturación total, cantidad de registros de venta y ticket promedio.
•	Ranking de productos: identificación de los cinco productos con mayor facturación.
•	Clientes recurrentes: identificación de clientes con más de un registro de venta y cálculo de sus gastos.
•	Comparación mensual: comparación de la facturación mensual con el promedio del período.
•	Relación entre tablas: combinación de información de ventas, clientes, productos y categorías mediante INNER JOIN.
**Aclaración:** el ticket promedio calculado corresponde al promedio del importe por registro de venta, no necesariamente al promedio por pedido único.
Cómo ejecutar los scripts
1.	Instalar SQL Server y abrir SQL Server Management Studio.
2.	Conectarse a la instancia de SQL Server correspondiente.
3.	Abrir o seleccionar el script SQL deseado desde el repositorio de GitHub.
4.	Copiar el código en una nueva consulta de SSMS o abrir el archivo .sql.
5.	Verificar que la base de datos Ventas_Tech_DB esté disponible.
6.	Ejecutar el script y revisar los resultados obtenidos.
Importante: si la base de datos no está instalada, será necesario crearla o restaurarla y cargar las tablas y los datos antes de ejecutar las consultas.
Estructura del repositorio
El repositorio organiza los archivos desarrollados durante los distintos módulos del curso. Cada script contiene consultas relacionadas con una etapa del proyecto RetailPro.
Los nombres y las ubicaciones de los archivos pueden consultarse directamente en las carpetas del repositorio.
Conclusiones
El proyecto permite aplicar SQL al análisis de información comercial, identificar productos relevantes, estudiar el comportamiento de los clientes y analizar la facturación.
**Período analizado:** los resultados disponibles corresponden a marzo, con una facturación total de $6.444. Estos datos permiten describir el período analizado, pero no son suficientes para confirmar tendencias de largo plazo. La documentación facilita la comprensión del trabajo y permite que otros analistas puedan revisar y continuar el proyecto.
